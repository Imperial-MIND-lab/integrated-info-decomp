# Examples

- **[`phiid_walkthrough.ipynb`](phiid_walkthrough.ipynb)** — a hands-on
  introduction to `phyid`: the `calc_PhiID` workflow, reading the 16 information
  atoms, aggregating them into familiar quantities (storage, transfer, synergy),
  and visualizing the atom lattice. Worked on four small systems whose
  information structure is known in advance (redundant, transfer, synergistic,
  independent), so the decomposition is interpretable.
